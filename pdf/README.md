# Dossier des épreuves

Déposez ici, pour chaque année, les trois PDF officiels du CEB publiés par la Fédération Wallonie-Bruxelles :

```
2025_CEB_questionnaire.pdf
2025_CEB_correction.pdf
2025_CEB_portfolio.pdf
```

La casse n'a pas d'importance (`2025_CEB_Questionnaire.pdf` fonctionne aussi). Ces fichiers ne sont pas versionnés dans Git.
