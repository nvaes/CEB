# Révision CEB — guide pour les parents

Ce site aide votre enfant à préparer le **CEB** (Certificat d'études de base) avec les **vraies épreuves officielles** des années précédentes. Il fonctionne dans le navigateur d'une tablette, d'un ordinateur ou d'un téléphone : rien à installer, aucun compte en ligne.

L'administrateur du site vous a donné :

- **l'adresse du site** (à ouvrir dans le navigateur) ;
- **votre code parent** à 6 chiffres — il identifie votre famille, gardez-le pour vous.

### Adresse sécurisée (https)

Préférez l'adresse qui commence par **https://** (port 8443) : les échanges entre la tablette et le serveur sont alors chiffrés.

La première fois, le navigateur affiche un avertissement du type « Votre connexion n'est pas privée ». C'est normal : le certificat du site est créé par l'administrateur, et non acheté auprès d'un organisme. Touchez **Paramètres avancés → Continuer vers le site** (Chrome, Edge) ou **Afficher les détails → visiter ce site web** (Safari, iPad). Le navigateur s'en souvient ensuite.

> N'acceptez cet avertissement que pour l'adresse donnée par l'administrateur. Si l'avertissement réapparaît sans raison plus tard, prévenez-le avant de continuer.

## 1. Première utilisation (5 minutes)

### Associer la tablette à votre famille

À faire une seule fois par appareil.

1. Ouvrez l'adresse du site.
2. Sur l'écran « Qui révise aujourd'hui ? », touchez **« Associer à ma famille »** (ou passez par **🔒 Parents → ⚙️ Réglages → Associer cette tablette à ma famille**).
3. Tapez votre code parent.

La tablette n'affichera plus que **vos** enfants. Astuce : ajoutez le site à l'écran d'accueil (menu du navigateur → « Ajouter à l'écran d'accueil ») pour l'ouvrir comme une application.

### Créer le profil de votre enfant

1. Touchez **🔒 Parents** et tapez votre code parent.
2. Onglet **👨‍👩‍👧 Enfants → ＋ Ajouter un enfant**.
3. Choisissez un prénom, un avatar et une couleur.
4. Votre enfant choisit **son code secret à 6 chiffres** et le tape deux fois.

Un profil par enfant : chacun retrouve sa propre progression.

## 2. Les codes à 6 chiffres

| Code | Qui l'utilise | À quoi il sert |
|---|---|---|
| **Code parent** | vous | ouvrir l'espace Parents, associer une tablette, ajouter un enfant |
| **Code de l'enfant** | votre enfant | ouvrir son profil, pour que frères et sœurs ne mélangent pas leurs réponses |

- Tous les codes ont **exactement 6 chiffres**. Évitez 123456, 000000 ou une date de naissance.
- **Votre enfant a oublié son code ?** Espace Parents → **Enfants → 🔑 Réinitialiser le code** : il en choisira un nouveau à sa prochaine connexion.
- **Changer votre code parent :** Espace Parents → **⚙️ Réglages → Changer mon code parent**.
- **Vous aviez un code à 4 chiffres ?** Il fonctionne encore une fois ; le site vous demande ensuite d'en choisir un à 6 chiffres. C'est pareil pour les enfants.

### Trop d'erreurs ?

- Après **5 codes faux d'affilée**, la saisie est bloquée 30 secondes, puis un peu plus longtemps à chaque nouvelle erreur.
- Après **10 erreurs en 10 minutes**, l'appareil (en fait votre connexion Internet) est **bloqué 1 heure** par la protection du serveur. Le site ne répond plus du tout. Attendez, ou prévenez l'administrateur, qui peut vous débloquer tout de suite.

> Toute la maison partage souvent la même connexion. Si un enfant s'acharne sur le clavier, les autres tablettes de la maison peuvent être bloquées aussi.

## 3. Ce que votre enfant peut faire

| Menu | Pour quoi faire |
|---|---|
| **Accueil** | son tableau de bord : progression en français, en mathématiques et en éveil |
| **Épreuves** | toutes les années, livret par livret, avec la correction officielle |
| **S'entraîner** | séries de questions mélangées par compétence (ex. : toutes les questions de « Grandeurs ») |
| **À revoir** | les questions ratées reviennent, puis réapparaissent quelques jours plus tard pour bien retenir |
| **Examen blanc** | un livret complet, chronométré comme le jour J, corrigé à la fin |
| **Exercices** | petites séries rapides : tables, calcul mental, conversions, conjugaison, homophones… |

### Répondre directement à l'écran

Au-dessus des pages, une barre d'outils :

| Outil | Usage |
|---|---|
| 👆 **Cocher / écrire** | toucher une case pour la cocher, écrire sur une ligne de réponse |
| ✗ **Croix** | poser une croix n'importe où (tableaux, cartes…) |
| Aa **Texte** | écrire un mot ou un nombre n'importe où sur la page |
| ✏️ **Crayon** | dessiner : tracés, schémas, flèches, calculs |
| 🧽 **Gomme** | effacer un trait ou une croix |

**Couleurs d'encre** : à droite des outils, 5 pastilles — **bleu** (par défaut), **rouge**, **vert**, **noir** et **blanc**. Choisissez la couleur *avant* d'écrire ou de dessiner. Le blanc sert de correcteur pour masquer un trait. Idée : l'enfant répond en bleu, vous corrigez ensemble en vert ou en rouge.

Les réponses sont enregistrées automatiquement. Votre enfant peut aussi répondre sur papier.

### La correction

- Les **cases à cocher** sont corrigées automatiquement quand c'est possible.
- Le reste se compare à la **correction officielle**, affichée à côté. L'enfant (ou vous) indique les points obtenus.
- **🎧 Écouter** : pour les épreuves d'écoute, la tablette lit le texte à voix haute (ou un adulte le lit).

## 4. L'espace Parents

Touchez **🔒 Parents** puis tapez votre code. Il se **verrouille tout seul** quand vous le quittez, au rechargement de la page ou après 4 heures. Pensez quand même à toucher **🔒 Verrouiller** avant de rendre la tablette.

| Onglet | Contenu |
|---|---|
| **📈 Progrès** | réussite par discipline et compétence, jours d'activité, examens blancs, **simulation du CEB** (50 % par épreuve), export CSV |
| **👨‍👩‍👧 Enfants** | ajouter, modifier, réinitialiser le code, remettre à zéro, supprimer |
| **⚙️ Réglages** | thème clair/sombre, votre code parent, association de la tablette |

Vous ne voyez **que vos enfants**. Les autres familles ne voient pas les vôtres.

---

## 5. Conseils

- **Peu mais souvent** : 15 à 20 minutes par jour valent mieux qu'une longue séance le week-end.
- Commencez par **S'entraîner** et **Exercices**, gardez l'**Examen blanc** pour les dernières semaines.
- Regardez **À revoir** ensemble une fois par semaine : c'est là que se trouvent les vraies difficultés.
- Pour l'examen blanc de mathématiques, préparez une latte, une équerre et un compas.

## 6. Questions fréquentes

**« Votre connexion n'est pas privée » s'affiche.**
C'est attendu avec l'adresse https la première fois (voir section « Adresse sécurisée »). Si cela revient alors que vous l'aviez déjà accepté, demandez à l'administrateur avant de continuer.

**Le site ne s'ouvre plus du tout.**
Votre connexion est peut-être bloquée après trop de codes faux. Attendez une heure, ou contactez l'administrateur.

**Mon enfant n'apparaît pas sur la tablette.**
La tablette est associée à une autre famille, ou à aucune. Associez-la de nouveau avec votre code parent (section 1).

**Nous changeons de tablette.**
Associez la nouvelle tablette : la progression est gardée sur le serveur, pas sur l'appareil.

**Mes données sont-elles envoyées quelque part ?**
Non. Tout reste sur le serveur de l'administrateur : pas de publicité, pas de compte, rien n'est envoyé à l'extérieur. Les codes sont enregistrés sous forme chiffrée.

**D'où viennent les épreuves ?**
Ce sont les épreuves officielles du CEB publiées par la Fédération Wallonie-Bruxelles, utilisées pour un usage privé.
